# santoku-matrix

The data layer for santoku: typed numeric containers for machine learning and retrieval
work. Dense matrices (`mtx`), sparse matrices (`csr`), labelled span sets (`spans`), the
zero-indexed typed vectors they are built on, plus mmap-backed vectors and C-level hash
maps and sets.

## Documentation

Runnable examples and the full API: [santoku.dev](https://santoku.dev/#santoku-matrix).

For agents and LLM tooling: [llms.txt](https://santoku.dev/llms.txt) for the index,
[llms-full.txt](https://santoku.dev/llms-full.txt) for every documented example.
